# TICKS // Real-Time Wealth Velocity Engine

> **Live Application**: [ticks.maksimluzik.com](https://ticks.maksimluzik.com)  
> High-performance, zero-backend, interactive single-page visualization displaying real-time wealth accumulation per second of the world’s richest individuals alongside socioeconomic class benchmarks.

---

## ⚡ Overview

**TICKS** is a client-side web application designed to bridge the human cognitive gap when conceptualizing extreme wealth disparity. Human perception is calibrated to hourly wages, monthly paychecks, and annual salaries. In contrast, modern billionaire wealth expands through exponential equity growth, capital appreciation, and asset inflation—operating at velocities where hundreds or thousands of dollars accumulate every fractions of a second.

TICKS visualizes this disparity through smooth 60fps real-time tickers, interactive side-by-side wage race simulations, dynamic class parity clocks, and logarithmic scale comparisons, running entirely in the browser with **zero build steps or backend servers**.

## ✨ Key Features

### 1. Global Session Tracker ("Since You Arrived")
- **Persistent Elapsed Timer**: High-precision `HH:MM:SS` counter running from the exact millisecond the user loads the tab.
- **Combined Wealth Readout**: Aggregated wealth generated by all featured billionaires combined since page initialization.
- **Micro-Interactions**: Visual pulsing indicator, live rate summaries, and simulation speed toggles (`1x`, `5x`, `10x`, `60x`, `3600x`, and `Pause`).

### 2. Socioeconomic Class Reference Tickers ("The Human Scale")
Dedicated comparison rails calibrating standard income brackets into live fractional-cent accumulation counters:
- **Lower Class**: ~$30,000/yr (~$0.00095/sec | ~$3.42/hr | ~$82.19/day) — *Bottom 20% income tier*.
- **Middle Class**: ~$75,000/yr (~$0.00238/sec | ~$8.56/hr | ~$205.48/day) — *Median US household benchmark*.
- **Upper-Middle Class**: ~$160,000/yr (~$0.00507/sec | ~$18.26/hr | ~$438.36/day) — *Top 15% household benchmark*.
- **Baseline Anchors**: US Federal Minimum Wage ($15,080/yr), BLS Median Individual Worker ($59,384/yr), and Global Median Earner ($2,500/yr).
- **Sub-Cent Accumulation**: Visualizes fractional micro-cents (`$0.000000`) climbing continuously.

### 3. Billionaire Leaderboard & Real-Time Velocity Cards
Live 60fps accumulation cards for the world's most prominent wealth accumulators:
- **Featured Profiles**: Elon Musk (Tesla, SpaceX, xAI), Jeff Bezos (Amazon, Blue Origin), Mark Zuckerberg (Meta), Bernard Arnault (LVMH), Larry Ellison (Oracle), Warren Buffett (Berkshire Hathaway), and Jensen Huang (NVIDIA).
- **Multi-Frequency Rates**: Real-time breakdown per second, minute, hour, day, and full year.
- **Dynamic Class Parity Clocks**: Live calculated countdowns revealing how fast each billionaire eclipses an entire working year of each socioeconomic class:
  - *e.g., "Surpassed Lower Class Annual Salary in 21.0s"*
  - *e.g., "Surpassed Middle Class Annual Salary in 52.6s"*
  - *e.g., "Surpassed Upper-Middle Annual Salary in 112.3s"*

### 4. Interactive "Race Your Salary & Class" Visualizer
- **Preset or Custom Income**: One-click selection for Lower, Middle, and Upper-Middle class, or custom inputs for hourly wage, monthly pay, or annual salary in USD or EUR.
- **Dual Progress Race**: Real-time visual race comparing the user's earnings against any selectable billionaire.
- **Contextual Milestone Triggers**: Pop-in badge alerts whenever the billionaire accumulates relatable life expenses relative to the user's timeline:
  - Specialty Espresso Drink ($6)
  - Monthly Family Grocery Budget ($450)
  - Median US Monthly Rent ($1,850)
  - 6-Month Emergency Cushion ($18,000)
  - Brand New Automobile ($38,000)
  - 4-Year University Degree ($42,000)
  - 20% Home Down Payment ($84,000)
  - Full Home Cash Purchase ($420,000)

### 5. Comparative Scale Visualizer (Logarithmic vs. Linear)
- Zero-dependency SVG visualizer charting standard income levels against billionaire velocities.
- Switchable between **Logarithmic Scale** (to perceive all tiers on one canvas) and **Linear Scale** (demonstrating how working-class bars flatten to invisible sub-pixel slivers).

### 6. Dynamic Live Data Sync
- **Forbes Real-Time Billionaires**: Automatically syncs daily net-worth historical time series directly in the browser via `komed3/rtb-api`.
- **Live FX Currency Exchange**: Fetches up-to-date USD/EUR currency exchange rates via `open.er-api.com` with seamless offline fallbacks.

### 7. Synthesized Web Audio
- Procedural audio cues using the native browser **Web Audio API** (subtle mechanical ticks and harmonic milestone chimes) without external MP3/WAV assets.

### Authoritative Empirical References

The socioeconomic benchmarks and growth trajectories referenced in TICKS are derived from the following economic studies and institutional datasets:

1. **U.S. Federal Reserve — Survey of Consumer Finances (SCF) & Distributional Financial Accounts (DFA)**
   - *Reference*: Board of Governors of the Federal Reserve System, *Wealth Inequality in the United States & Distribution of Household Wealth (1989–2024)*.
   - *Key Finding*: The top 1% of households hold over 30% of total national wealth, while the bottom 50% hold approximately 2.5%. Between 2019 and 2024, real net worth of the top 0.1% expanded by more than 45%, driven by equity market concentration, compared to an average 4% real gain for the bottom quintile.

2. **World Inequality Database (WID) & Distributional National Accounts (DINA)**
   - *Reference*: Alvaredo, F., Chancel, L., Piketty, T., Saez, E., & Zucman, G. (2018–2024). *World Inequality Report*.
   - *Key Finding*: Since 1995, the top 1% captured 38% of all global wealth growth, whereas the bottom 50% captured just 2%. The growth rate for centimillionaires and billionaires averaged 6–9% per year *above* global GDP growth.

3. **U.S. Bureau of Labor Statistics (BLS) — Consumer Expenditure Surveys & Employment Cost Index (ECI)**
   - *Reference*: BLS Series *Median Weekly Earnings of Full-Time Wage and Salary Workers* & *Occupational Employment and Wage Statistics (OEWS)*.
   - *Key Finding*: Adjusted for the Personal Consumption Expenditures (PCE) price index, real median wages for non-supervisory workers have grown less than 0.7% annually over the last three decades, resulting in stagnant purchasing power for basic life necessities.

4. **U.S. Census Bureau — Income and Poverty in the United States**
   - *Reference*: Current Population Reports, Series P60-279 (Historical Income Tables: Household Equivalence-Adjusted Gini Index).
   - *Key Finding*: The household Gini coefficient in the US increased from 0.397 in 1967 to over 0.490 in the 2020s, showing persistent polarization between labor income and capital-derived returns.

5. **Congressional Budget Office (CBO) — Trends in the Distribution of Family Wealth**
   - *Reference*: CBO Report No. 58319, *Trends in Family Wealth: 1989 to 2022*.
   - *Key Finding*: Total real family wealth tripled from 1989 to 2022, but the distribution became markedly more unequal. Families in the top 10% owned 72% of total wealth in 2022 (up from 63% in 1989), while families in the bottom 25% were in net debt.

6. **Oxfam International & Credit Suisse / UBS Global Wealth Reports**
   - *Reference*: Oxfam Global Inequality Reports (*Inequality Inc.*, 2024 & *Survival of the Richest*, 2023); UBS *Global Wealth Report 2024*.
   - *Key Finding*: The fortunes of the world's five richest men surged by 114% in real terms since 2020 (at a rate of $14 million per hour), while five billion people became poorer due to inflation and living-cost spikes.

## 🧮 Mathematical Model & Methodology

### Wealth Velocity vs. Static Cash Income

A fundamental misconception when examining billionaire wealth is comparing it to a W-2 salary:
- **W-2 Cash Income (Flow)**: Money paid out periodically for labor, subject to standard withholding, payroll taxes, and capped by working hours ($2{,}080\text{ hours/year}$).
- **Wealth Velocity (Derivative of Stock)**: The continuous instantaneous change in market valuation of equity holdings, options, dividends, and real assets.

### Fundamental Velocity Formula

$$\text{Earnings per Second} = v = \frac{\Delta\text{Net Worth}}{\Delta t_{\text{seconds}}} = \frac{\Delta\text{Net Worth}}{31{,}536{,}000}$$

Where $31{,}536{,}000 = 365 \times 24 \times 3{,}600$ represents the total calendar seconds in a standard year.

### Calculation Modes
1. **5-Year Annualized Growth (Default)**:
   $$\Delta\text{Net Worth} = \frac{\text{Net Worth}_{t} - \text{Net Worth}_{t-5}}{5}$$
   *Smooths out single-year volatility, bear markets, and tech-cycle spikes to highlight long-term compounding.*
2. **Trailing 12-Month (TTM) Growth**:
   $$\Delta\text{Net Worth} = \text{Net Worth}_{t} - \text{Net Worth}_{t-1}$$
   *Captures near-term momentum, AI infrastructure rallies, and recent equity surges.*

### Class Parity Time Formula

The exact seconds required for a billionaire to accumulate the entire annual income of a given socioeconomic tier:

$$T_{\text{parity}} = \frac{\text{Annual Income}_{\text{Tier}}}{v_{\text{Billionaire}}}$$

## 🚀 Local Development & Deployment

### Run Locally
Since the application requires zero build tools, you can run it with any static web server:

```bash
# Using Python
python -m http.server 8989

# Using Node (npx)
npx serve -p 8989 .

# Or via npm (runs on port 8989)
npm start

# Or open index.html directly in any modern browser
```

Visit `http://localhost:8989` in your web browser.

### GitHub Pages Deployment
1. Commit and push files to your repository's `main` branch. A workflow (`.github/workflows/pages.yml`) deploys automatically when **Settings → Pages → Source** is set to **GitHub Actions**; alternatively choose `Deploy from a branch` → `main` / `root` (`.nojekyll` is included).
2. In GitHub repository settings: **Pages** → **Source** → `Deploy from a branch` → `main` / `root`.
3. Configure the custom domain `ticks.maksimluzik.com` (persisted in the root `CNAME` file).
4. Point DNS CNAME record:
   - Host: `ticks`
   - Value: `<your-github-username>.github.io`
   - Enable **Enforce HTTPS**.
